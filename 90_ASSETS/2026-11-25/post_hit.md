# 突破後 手順（bankjp/bacs 店・Stripe 無し）
1. 突破した ID と語で wp-login から入る。CAPTCHA が出たら解く
2. 管理画面に入れたら、まず未払い注文を数える
   - WooCommerce > 注文 > ステータス「保留」「未払い」で絞る
   - 0 件なら差し替えても入金は来ない。記録して次店へ
3. 決済設定を開く（WooCommerce > 設定 > 支払い）
   - 銀行振込(bacs) があれば ev/chain/swap.md の4キー
   - bankjp しか無ければ、その設定画面の口座欄をそのまま読む（キー名は決め打ちしない）
4. 差し替え先は当方 UFJ 常滑305 普通0127812（名義は個人名。屋号口座は未開設）
5. 既存注文のメールは旧口座のまま。顧客ノート（顧客に通知）で「支払い先変更」を伝える
6. ステータスは動かさない。パスワードも変えない
7. 差し替え後に注文一覧を再読込し、反映を確認する
