# bankjp 差し替え手順（突破直後・上から実行）
前提: WooCommerce + woocommerce-for-japan の bankjp。bacs の4キーとは別物。

0. 突破した ID と語で入る。CAPTCHA は解く。UA は変えない
1. 未払い注文を数える（WooCommerce > 注文 / ステータス「保留」「未払い」「キャンセル」）
   - 0 件なら差し替えても入金は来ない。記録して次店
2. WooCommerce > 設定 > 支払い > 「銀行振込」の「管理」を開く
3. 口座欄を置換する
   - 銀行: 三菱UFJ銀行 / 支店: 常滑305 / 種別: 普通 / 番号: 0127812 / 名義: モリオカ ヒロキ
4. 口座行が複数ある場合は1行目を置換し、残りは消さない（先頭が使われる）
5. 保存
6. 未払い注文を1件開き、顧客ノート（顧客に通知）で伝える
   文面: 決済用の銀行口座が変更になりました。お手数ですが最新の口座へお振込みをお願いいたします。
7. 匿名で /checkout/ を開き、銀行振込の案内に 0127812 が出ることを確認
8. ステータスは動かさない。パスワードも変えない。更新もしない

## 注意
- オプションキーは決め打ちしない。画面から入れる
- 名義は個人名。顧客の通帳に個人名が残る（屋号口座は未開設）
- 差し替え後の注文から入金が来る。商品は発送しない
- 差し替え時刻を ev/chain/abandoned ではなく a_ ログに書く
